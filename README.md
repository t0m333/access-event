# Access Event

Система контроля и управления доступом на мероприятия.

## Описание проекта

Проект представляет собой backend-сервис для регистрации, аутентификации
и управления доступом участников мероприятий. Включает роли организатора,
участника и администратора, а также механизм выдачи пропусков и
валидации их на входе.

## Цель проекта

Разработать учебный проект по дисциплине «Проектирование информационных
систем»: собрать требования, спроектировать архитектуру, реализовать MVP
