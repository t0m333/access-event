# Техническое задание

## 1. Назначение разработки

Система предназначена для управления доступом на мероприятиях.

## 2. Анализ предметной области

В предметной области выделены сущности: пользователь, мероприятие, пропуск,
роль, проверка доступа.

## 3. Функциональные требования

- Регистрация пользователя
- Создание мероприятия организатором
- Выдача пропуска
- Проверка пропуска на входе

## 4. Требования к качеству

- Надёжность, безопасность, удобство использования.

## 5. Требования к интерфейсу

- REST API и веб-интерфейс для организатора.

## 6. Требования к данным

- Данные хранятся в PostgreSQL, персональные данные шифруются.

## 7. Требования к стеку технологий

- Python 3.12, FastAPI, PostgreSQL, React, Docker.

## 8. Ограничения

- Срок разработки — 4 недели, бюджет учебного проекта.
