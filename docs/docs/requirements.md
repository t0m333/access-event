# Требования

## User Stories

1. Как участник, я хочу зарегистрироваться на мероприятие, чтобы получить пропуск.
2. Как участник, я хочу отменить регистрацию, чтобы освободить место.
3. Как участник, я хочу видеть список своих мероприятий, чтобы планировать время.
4. Как организатор, я хочу создать мероприятие, чтобы начать регистрацию.
5. Как организатор, я хочу видеть список зарегистрированных участников.
6. Как организатор, я хочу экспортировать список участников в CSV.
7. Как администратор, я хочу блокировать пользователя, чтобы предотвратить нарушения.
8. Как администратор, я хочу видеть журнал всех событий доступа.
9. Как охрана, я хочу сканировать QR-код пропуска на входе.
10. Как охрана, я хочу видеть сообщение об ошибке при недействительном пропуске.
11. Как участник, я хочу получать уведомление о подтверждении регистрации.
12. Как организатор, я хочу редактировать мероприятие до его начала.

## Нефункциональные требования (NFR)

- NFR-1: Время ответа API не должно превышать 300 мс при 95 перцентиле.
- NFR-2: Система должна выдерживать 1000 одновременных пользователей.
- NFR-3: Пароли хранятся в виде bcrypt-хэшей.
- NFR-4: Все запросы к API проходят через HTTPS.
- NFR-5: Логи хранятся не менее 90 дней.
- NFR-6: Доступность сервиса не ниже 99,5%.
